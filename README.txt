MI DROGUERO 3.0
================
Paquete PWA para celular, continuación de Mi Droguero 2.0.

Incluye modo Alumno/Docente, inventario, registro, buscador, alertas,
etiquetas, panel docente, CSV, seguridad y botón de instalación PWA.

IMPORTANTE: esta entrega funciona en modo DEMO local. La base de datos
compartida requiere conectar Supabase (se incluye esquema SQL y configuración).

Para que los alumnos la tengan en el celular:
1) Publicar index.html, manifest.json y sw.js en un hosting HTTPS.
2) Abrir la URL en el celular.
3) Elegir "Instalar aplicación" o "Agregar a pantalla de inicio".
4) Crear un QR con esa URL y compartirlo con los alumnos.

El ZIP no se instala directamente: es el paquete que se publica.
Uso exclusivamente escolar simulado; no gestionar sustancias peligrosas reales.
